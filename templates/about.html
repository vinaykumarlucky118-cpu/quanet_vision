Academic Research Specification

About QuaNet Vision

An intelligent hybrid IoT–satellite deep learning platform for continuous water-quality prediction, spatial remote sensing, and early environmental hazard prevention.

Project Description

QuaNet Vision is a hybrid AI-based water quality monitoring and prediction platform that synergistically integrates:

IoT Sensor Telemetry

In-situ multi-parameter chemistry (pH, Temp, Turbidity, DO, TDS, Conductivity).

Satellite Remote Sensing

High-resolution optical satellite tiles for regional algal bloom and sediment detection.

CNN + LSTM Fusion

Deep multimodal fusion unifying temporal parameter trajectory and spatial textures.

Main Aim

"To develop an intelligent hybrid IoT–satellite deep learning system that monitors and predicts water quality and helps detect possible pollution at an early stage."

Project Objectives

  • Monitor water-quality parameters continuously (pH, DO, Turbidity, etc.).
  • Analyze historical sensor time-series data.
  • Analyze optical satellite imagery for water surface characteristics.
  • Extract spatial image features using Convolutional Neural Networks (CNN).
  • Model temporal dynamics using Long Short-Term Memory (LSTM).
  • Combine multi-source features via multimodal late data fusion.
  • Predict water quality class (GOOD / MODERATE / POOR) with confidence metrics.
  • Detect anomalous pollution spikes and trigger proactive alerts.
  • Deliver interactive dashboard visualizations and comprehensive report generation.

Problem Statement

Traditional water-quality monitoring relies heavily on manual sampling and laboratory testing. This process can be time-consuming, expensive and difficult to perform continuously over large geographical areas. Remote water bodies may not be monitored frequently, resulting in delayed identification of pollution or water-quality deterioration.

QuaNet Vision proposes a hybrid approach that combines IoT-based water-quality data and satellite imagery with deep learning techniques to provide intelligent water-quality prediction and monitoring.
