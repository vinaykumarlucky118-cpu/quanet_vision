Methodology & Workflow

How QuaNet Vision Operates

From in-situ IoT telemetry and orbital satellite imagery to deep multimodal neural network fusion and real-time dashboard analytics.

8-Stage End-to-End Workflow

01

1. Data Collection

In-situ telemetry polls pH, Temp, Turbidity, DO, TDS, and Conductivity.

02

2. Satellite Data

Optical satellite imagery captures spatial surface conditions and regional water body scope.

03

3. Preprocessing

StandardScaler normalizes telemetry; image tiles resized to 128x128 with NDWI filtering.

04

4. CNN Vision

Convolutional layers extract spatial turbidity gradients and chlorophyll pigment features.

05

5. LSTM Dynamics

Recurrent cells analyze sliding time-series windows to detect parameter rate-of-change.

06

6. Data Fusion

Multimodal fusion layer merges temporal and spatial representation embeddings.

07

7. Prediction

Classifies state (GOOD / MODERATE / POOR) with statistical confidence metrics.

08

8. Dashboard & Alert

Renders interactive charts, notifies thresholds, and generates PDF compliance reports.

CNN — Convolutional Neural Network Spatial Vision

CNN is utilized for computer vision feature extraction from optical satellite tiles:

Satellite Image → Conv2D + BatchNorm + MaxPool → Spatial Feature Embedding (32D)
CNN Visual Pattern Targets:
  • Turbidity Index: Red/Blue optical ratio indicating sediment plumes.
  • Algal Blooms: Green chlorophyll absorption and NDWI proxy.
  • Suspended Particulates: Surface texture variance & Laplacian entropy.
LSTM — Long Short-Term Memory Sequential AI

LSTM is tailored for multi-sensor sequential time-series modeling:

Sequential Sensor Telemetry (t-k ... t) → 2-Layer LSTM → Temporal Feature Vector
LSTM Temporal Targets:
  • Diurnal Temperature Cycles: Day/night fluctuation modeling.
  • DO Depletion Velocity: Detects hypoxic decay trends before collapse.
  • TDS & Salinity Creep: Captures cumulative mineral buildup over hours.

CNN vs. LSTM Comparison Matrix

Feature Dimension CNN (Convolutional Neural Network) LSTM (Long Short-Term Memory)
Domain Computer Vision / Remote Sensing Sequential / Time-Series Modeling
Primary Input Multispectral / RGB Satellite Tiles (128x128x3) 6-Parameter Sensor Vector Streams
Extracted Information Spatial textures, algal bloom dispersion, surface clarity Temporal trajectory, velocity of parameter changes, diurnal patterns
Core Mechanism 2D Convolutions + Pooling + Dense Embedding Recurrent Memory Cells (Forget, Input, Output Gates)
